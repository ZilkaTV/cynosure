## MESSAGE 1 (image: banner-en.png)

# 🚀 CynClan.com update
The site now has a **Live Ranked Queue** for the top 100 in 1v1 and 2v2 – so you can see when the top boards are busy and stop waiting half an hour in the queue. 👀

**🎯 Live Ranked Queue** (menu: between Speedrun and History)
• Finished ranked 1v1 / 2v2 games with at least one top-100 player
• Map, duration, both teams, **winner ✓**, rank + Elo, and the **game ID** on the right
• **Click a row** → game report with the replay link
• 1v1 is violet, 2v2 is teal – refreshes every 20 seconds
• Names are shown as used in the game. Rank and Elo only appear for players using their own account name – we don't unmask anyone.
• **Elo +/−** per game appears after OpenFront's hourly ranking update (several games = a sum, e.g. "Σ +34 (3)")

## MESSAGE 2 (image: alerts-en.png)

**🚦 Traffic light** – counts the different top-100 players who finished a game in the last 30 minutes:
🔴 under 5 = quiet · 🟡 5–11 = medium · 🟢 12+ = busy, queue now!

**🔔 Notifications** – one switch each for **1v1** and **2v2**. Switch on → your browser asks for permission. On a new top-100 game you get a red dot, a blinking tab title, a short beep and a pop-up. Use **"Test"** to try it. Works while cynclan.com is open in a tab.

**Abandoned games** are grey. 2v2: match cancelled, nobody's Elo changes. 1v1: a player who didn't spawn can lose Elo – unless OpenFront detects connection problems, then nobody loses points.

## MESSAGE 3 (image: speedrun-en.png)

**✓ Speedrun: Verified** – a white check mark means the time was **replayed in the real game engine** and every rule was met (Australia, 400 bots, no nations, no cheats). No speed manipulation is possible.

**⭐ Save games** – press "☆ Save game" in a game report. Find them under **My profile** (top right) → Saved games.
